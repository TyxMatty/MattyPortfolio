// 02 · my own brand

The Jay line

Jay is my own family of lightweight, open-source desktop apps. They share the wolf, the look and the stack, and they work together: one for calls, one for audio, one for files and a hub that installs them all.

  • Light by design

    Tauri v2 instead of Electron, with the heavy work in Rust. Small installers, low memory, fast start.

  • One look

    Every app ships the same Calm, Neon and Soft styles, light or dark, in English or Portuguese.

  • Built to work together

    Jay-A hands Jay-C a filtered microphone over a local link, and Jay-H installs and updates the whole line.

  • Open and yours

    MIT licensed, no accounts, no ads. Updates come straight from the public GitHub releases.

C

Jay-C calls & screen sharing · flagship

Lightweight, open-source calls and screen sharing for desktop and mobile, on a server you control.

1 / 3

Jay-C runs on a signaling server that you or a friend host with a single docker compose up. No accounts, no ads, no third-party cloud in the middle of your calls.

Built with Tauri v2 (Rust) and Vanilla JS, with a mediasoup SFU in Node.js: each person uploads their stream once and the server forwards it to up to 16 people, without decoding it. A native Windows plugin captures per-process audio, so you can stream a game with its sound and leave Discord out.

security by design

  • Media encrypted in transit with WebRTC DTLS-SRTP
  • Signaling hardened with per-connection token-bucket rate limits, a 64 KB message cap and an optional origin allowlist
  • Strict Content Security Policy in the app: scripts only from the app itself
  • Self-hosted: your calls stay on infrastructure you control
  • Open source under the MIT license

Jay-A audio

The audio app of the line: a clean voice for Jay-C calls without a noise-removal subscription. It runs in the tray and feeds Jay-C through the Jay Link; if Jay-A stops, the call keeps going on Jay-C's own filter.

  • AI noise removal (DeepFilterNet or RNNoise) plus WebRTC cleanup
  • Effect chain: filter, gate, EQ, compressor, de-esser, limiter, with presets
  • Soundboard, audio editor and converter on the way
  • Rust

// 03 · game in development

Steal a Creepypasta Sealed Entities

A multiplayer survival-theft game on Roblox, set in Creepypasta lore.

Players sneak into the Hazard Zone to steal cursed eggs, run them home past three patrolling Hunters, unseal the entity at their bunker altar and put it to work earning Essence, while defending their base with traps and raiding everyone else's.

  • 17 entities across 5 rarity tiers, rolled with luck
  • Boss fights with a live damage ranking
  • Bunker defense: traps, door hacking and raids
  • Powers, passes and a collectible index

anti-exploit

  • Server-authoritative: the client only sends intent
  • Server-side movement sanity check that puts teleporting exploiters back
  • Remote calls with payload validation (types, NaN, ranges) and per-player rate limits
  • Thefts checked against server state, never against client-side doors

The PRIINT Project (Projeto de Integração Internacional Tecnológica)

The PRIINT Project (Projeto de Integração Internacional Tecnológica) is an initiative I developed alongside my partner, in collaboration with the State University of Ponta Grossa (UEPG). Our core mission is to integrate all kinds of people into the learning process, with a strong focus on accessibility for people with disabilities.

Designed for educational institutions, the software utilizes AI to provide personalized learning experiences, adapting to each student's unique needs and preferences. Built with Python and TypeScript, and integrating LLMs like Gemini and ChatGPT, PRIINT aims to aid students from all over the world in their educational journey.
